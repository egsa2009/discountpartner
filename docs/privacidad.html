Política de Privacidad

Discount Partner — Última actualización: septiembre de 2025

1. Información que recopilamos

Discount Partner es una herramienta automatizada que publica ofertas de Amazon en Instagram. No recopilamos datos personales de usuarios. La aplicación accede únicamente a la cuenta de Instagram del administrador para publicar contenido.

2. Uso de la información

Los datos de acceso a la API de Instagram se usan exclusivamente para publicar stories y posts con ofertas. No compartimos ninguna información con terceros.

3. Datos de la API de Meta

Discount Partner usa la API de Instagram Graph para publicar contenido. Los tokens de acceso se almacenan de forma segura y no se comparten con ninguna otra parte.

4. Cookies

Este sitio web no usa cookies ni tecnologías de rastreo.
